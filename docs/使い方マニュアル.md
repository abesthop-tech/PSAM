# 使い方マニュアル

ComfyUI用プロンプトの作成・管理を行うローカルアプリです。ここでは日常的な使い方だけをまとめます。

## 起動方法

プロジェクトフォルダ直下の **`起動.bat`** をダブルクリックしてください。
黒いウィンドウが2つ立ち上がり(裏側のサーバーです。閉じるとアプリが止まるので、使っている間は最小化しておけばOK)、数秒後に自動でブラウザが開きます。

開かなかった場合は手動で `http://localhost:5173` を開いてください。

終了するときは、開いた2つの黒いウィンドウを閉じてください。

---

## 画面の見方(左端のアイコン)

| アイコン | 画面 | できること |
|---|---|---|
| 🪄 Build | プロンプト作成 | 普段使うメイン画面。アイテムを組み合わせて最終プロンプトを作る |
| ✨ ComfyUI | ComfyUI送信 | プロンプトと生成条件をComfyUIへ送り、生成画像を確認する |
| ✨ クイック | クイック作成 | カテゴリーごとに素材を選んで素早くプロンプトを作る |
| 📚 Groups | グループ管理 | 「お気に入り」のようなグループの中身を編集する |
| 🔷 Items | Items管理 | アイテム(キャラ・単語など)そのものを新規作成/編集/削除する |
| 🗄 Database | Database Viewer | 中身をそのまま一覧で見る(トラブル確認用、普段は使わなくてOK) |

---

## 1. プロンプト作成画面(メイン)

1. **左カラム**で使いたいプール(Character/Expression/Compositionなど)を選ぶ
2. その下のグループ一覧から見たいグループをクリック(「(すべて)」を選ぶとグループ絞り込みなしで全件表示)
3. **中央カラム**にアイテムのカードが並ぶ。上部の「Part / Finished」タブで部品/完成品を切り替えられる
4. 使いたいカードを**クリック**すると右側に追加される
5. **右カラム**
   - `Added Items`: 追加済みのアイテム。✕で個別に削除できる(削除すると本文からもその分だけ自動で消える)
   - 複数バリエーションを持つアイテムは名前の横に **↻** が出る。クリックすると別のバリエーションに切り替わる
   - `Active LoRAs`: LoRAを持つアイテムを追加すると自動で表示される。スライダーや数値を変えると本文の `<lora:...:強度>` がリアルタイムで書き換わる
   - `Positive Prompt` / `Negative Prompt`: 自由に手で編集してOK。右上の `Copy` でクリップボードにコピー
   - `クオリティタグ` / `標準ネガ` ボタン: 定型文を挿入する。すでに入っている場合は二重に追加されない
   - オレンジ枠の「おすすめの組み合わせ」: 追加したアイテムに関連付けられた(Items管理画面で設定した)アイテムが表示される。クリックで追加

3カラムの境目はドラッグで幅を調整できます。

右下の「ComfyUIへ置換して渡す」では現在のPositiveを送信画面へ置き換えて渡し、「末尾へ追加して渡す」では送信画面に残っているPositiveの末尾へ追加します。

## 2. ComfyUI送信画面

ComfyUIを起動した状態で使用します。左サイドバー下部のランプは、緑が接続済み、赤が未接続です。

1. Checkpointを選択し、Positive／Negativeを確認・編集する
2. 必要に応じて「各種設定」でBatch size、Steps、CFG、Seed、Sampler、Schedulerなどを設定する
3. 「Hires fix」で倍率、2nd Steps、2nd CFG、Denoiseなどを設定する
4. 「実行」または `Ctrl+Enter` でComfyUIへ送信する
5. 右の「今回の生成」で生成画像を確認する。右欄の左端はドラッグで幅を変更でき、欄全体をスクロールできる

### LoRAの自動適用

- 作成画面から渡されたアイテム、Positive内の `<lora:...>` タグ、置換候補から絵柄LoRA／キャラクターLoRAを推測します。
- ComfyUIへ送る際はLoRAタグをPositive本文から除去し、ワークフローのLoRA Loaderとして適用します。
- ComfyUI側で実際に存在するLoRAパスへファイル名から解決します。
- Positive内のタグ推論は維持されますが、置換候補にLoRAがある場合は候補側で指定した強度が使われます。

### 置換生成

1. Positive内で置換したい文字列をドラッグ選択し、「置換対象に追加」を押す
2. 追加された行の「置換候補を選ぶ」を押す
3. カテゴリー／グループ／検索で候補を絞り、複数選択する
4. LoRA候補はModel Strength／CLIP Strengthを個別指定できる。一括値を入力して「選択中すべてに適用」も使用できる（初期値 `1.00`、増減幅 `0.05`）
5. ランダムでは重複しない組み合わせを指定件数分、網羅では候補の直積を送信する

「置換対象に追加」だけではモーダルは開きません。候補を変更するときに「置換候補を選ぶ」を押します。画面を移動して戻っても、入力内容・設定・置換候補はブラウザ内に保持されます。

### 生成画像のプレビュー登録

生成画像を選ぶと、その生成で使ったアイテムへプレビュー画像として登録できます。すでにプレビューがあるアイテムは登録対象に表示されません。今回の生成一覧はPSAMバックエンドを再起動するとクリアされます。

## 3. グループ管理画面

グループ = 「お気に入り」「LoRA有り」のような、アイテムをまとめる箱です。

- 左でプールとグループを選ぶ。右上の緑の `+` で新規グループ作成
- グループ名の横の鉛筆アイコンで改名、ゴミ箱アイコンで削除(グループ自体が消えるだけで、中のアイテムは残ります)
- 右側にそのグループの中身が並ぶ。カードをクリック(またはチェックボックス)で複数選択できる(Shiftキーで範囲選択、Ctrlキーで個別追加も可)
- **「選択したアイテムをグループから削除」**: 選んだアイテムをこのグループから外します。**アイテム自体は消えません**(他のグループや画面には残ります)
- **「グループにアイテムを追加」**ボタン: 検索モーダルが開くので、追加したいアイテムを選んで「追加する」
- 検索欄の隣の「グループ内 / プール全体」切り替え:
  - `グループ内`: 今のグループの中だけを検索・選択(削除操作用)
  - `プール全体`: プール全体から検索し、**カードをクリックするだけでこのグループに追加**されます(モーダルを開かずに素早く追加したいときに使う)

---

## 4. Items管理画面

アイテム(キャラ・服・単語など)そのものの新規作成・編集を行います。

- 上部の検索欄・プール・タイプで絞り込み
- 一覧の鉛筆アイコンで編集パネルが右からスライドして開く
  - **基本情報タブ**: 名前・プール・タイプ・Positive/Negative・バリエーション・LoRA設定・画像パス・メモ
  - **所属Gタブ**: このアイテムがどのグループに入っているか。追加/削除できる
  - **関連付けタブ**: 「おすすめの組み合わせ」に出す関連アイテムを設定する(プールをまたいでOK。例: キャラ⇔専用ポーズ)
  - 保存は右下の `Save Changes`。`Discard` で閉じると基本情報の未保存分は破棄されます(所属G・関連付け・バリエーションはその場で即保存されます)
- 右上の `新規アイテム` で空のパネルが開き、新規作成できます
- **「選択から完成品作成」**: 一覧のチェックボックスで**part(部品)**タイプのアイテムを複数選んでからこのボタンを押すと、選んだpartのpositiveを結合した新しい**finished(完成品)**アイテムを作れます(名前を付けて保存するだけ)

---

## 5. Database Viewer

右上のプルダウンでテーブルを切り替えて中身を一覧できます。普段の作業では使いませんが、「アイテムが増えているか確認したい」「グループの紐付けがおかしい気がする」といったときの確認用です。検索・ページ送りに対応しています。

## トラブルシューティング

- **画面が真っ白/動かない**: `起動.bat` で開いた2つの黒いウィンドウにエラーが出ていないか確認してください。閉じてしまった場合はもう一度 `起動.bat` を実行すれば再起動できます。
- **ComfyUIが未接続になる**: ComfyUIが `http://127.0.0.1:8188` で起動しているか確認してください。別URLを使う場合は `backend/local_settings.json` の `comfy_url` を変更します。
- **axesのJSONを直接編集した内容を反映したい**: バックエンドの黒いウィンドウを閉じ、コマンドプロンプトで
  ```
  cd backend
  venv\Scripts\python.exe -m app.migrate.migrate_json
  ```
  を実行すると、変更点だけがデータベースに反映されます(既存データが消えることはありません)。
